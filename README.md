# Praktikum Pemrograman Game 1–5

Repository ini berisi dokumentasi hasil praktikum mata kuliah Pemrograman Game menggunakan Unity 6 dan bahasa pemrograman C#.

## Informasi Project

- Mata Kuliah: Pemrograman Game
- Game Engine: Unity 6
- Versi Unity: 6000.0.6f1
- Bahasa Pemrograman: C#
- Platform Pengembangan: macOS
- Tujuan: Pembelajaran dan Portofolio Akademik

## Sumber Pembelajaran

Project ini dikembangkan berdasarkan modul praktikum yang diberikan oleh dosen pengampu mata kuliah Pemrograman Game.

Implementasi dilakukan sebagai bagian dari kegiatan pembelajaran, pengujian fitur, dan pengembangan keterampilan menggunakan Unity.

## Asset Pihak Ketiga

Beberapa asset yang digunakan dalam project berasal dari Unity Asset Store.

Hak cipta dan lisensi asset tetap menjadi milik masing-masing pemegang hak. File mentah asset pihak ketiga tidak disertakan dalam repository publik ini.

## Dokumentasi

Repository ini berisi dokumentasi implementasi, screenshot hasil praktikum, dan penjelasan fitur yang telah dikerjakan.

## Catatan

Repository ini dibuat untuk keperluan akademik dan portofolio pribadi, bukan untuk mengklaim kepemilikan materi modul maupun asset pihak ketiga.
